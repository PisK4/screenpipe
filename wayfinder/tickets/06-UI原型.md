### v2 改动（响应用户第一轮反应）

1. **视觉对齐现有 tab 风格**：弃用 DESIGN.md 的 phosphor 方案，改用 `app/globals.css` 暗色 token——`#121212` 底、白底黑字主按钮、22% 灰边框、6px 圆角，与 activity/pipes 等 section 一致。
2. **新增「自己写一个新方案」交互**（对齐 `Agent开发/cue/prototype/index.html` 的 `plan-compose` 模式）：方案列表末行虚线 radio 加输入框，回车或失焦钉成用户方案并选中，挂「你的方案」角标；铅笔编辑按 T4 砍掉不搬。
3. **新手接入卡落到真实机制**：fork 已有对外套件——`skills.rs` 的 `connect_detected_ai_tools_in_background` 探测本机 AI 工具（`~/.claude`、`~/.codex/config.toml`、`~/.cursor/mcp.json` 等）并把 Cue 本地 API 写进它们的 MCP 配置，另有 `install_external_agent_skills` 往外部 agent 装技能。卡面据此改写：依据行说明检测到哪些 agent、接入做什么、可随时断开；主按钮「接入」。

### 已按前序决议收口的口径

- 按钮：轻提示「知道了 / 不要」，提案「接受选中方案 / 不要」；「在对话里继续」随执行链路后置（T5 决议 5 的连带收窄）。
- Filter：待决定、已结束两个；已拒绝/已过期离开工作台只留库记录。
- 五状态图例各画一遍，「正在准备」标注为库里存在、工作台不可见的态（《03》§3 半成品不展示）。
